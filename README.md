# Hazardous Asteroid Prediction

This project builds a machine learning workflow to classify Near-Earth Objects (NEOs) as hazardous or non-hazardous based on orbital and physical features. The notebook trains and compares classification models and saves a final model that can be used for future predictions.

## Project overview

The notebook, `hazardous_asteroid_prediction_final.ipynb`, covers the full workflow:

- Data loading and preprocessing
- Exploratory data analysis (EDA)
- Feature engineering and selection
- Model training and comparison
- Explainability and feature importance analysis
- Model saving and deployment

## Dataset

The project expects a NASA asteroid dataset file matching the pattern `neo*.csv` in the same working directory as the notebook.

The notebook reads the CSV, prepares a target column named `hazardous`, and creates derived features such as:

- `avg_diameter`
- `absolute_magnitude`
- `relative_velocity`
- `miss_distance`
- `orbiting_body`
- `sentry_object`

## Models used

The notebook compares multiple supervised classification models, including:

- Logistic Regression
- Random Forest Classifier

The final trained model is saved as:

- `hazardous_asteroid_model.pkl`

## Prediction function

The notebook defines a helper function named `predict_hazardous(...)` that accepts asteroid measurements and returns:

- the predicted label (`Hazardous` or `Non-Hazardous`)
- the probability of the object being hazardous

Example:

```python
label, probability = predict_hazardous(
    absolute_magnitude=21.0,
    est_diameter_min=0.35,
    est_diameter_max=0.78,
    relative_velocity=45000,
    miss_distance=20000000,
    orbiting_body='Earth',
    sentry_object=False,
)

print(label, probability)
```
